Things 模式改造方案：月视图即一切

核心理念：离开日历的次数趋近于零

一、当前问题 vs 改造后

❌ 现在：功能孤岛

新建任务 → 弹出大模态框（14个字段）

看任务详情 → 弹出小浮窗（信息有限）

编辑任务 → 再次弹出大模态框

管理项目 → 独立的项目模态框

看矩阵 → 切换到完全不同的视图

周期规则 → 独立的规则管理器

✅ 改造后：月视图即中心

新建任务 → 点日期直接打字，回车即成

看详情 → 点任务在侧面板展开

编辑 → 侧面板里直接改，实时保存

项目 → 侧边栏列表，点一下日历过滤

矩阵 → 四个象限以图层叠加在日历上

周期 → 右键任务选「重复」，不离开日历

二、核心改造点

改造 ①：日期点选即输入

月视图每个日期格子里直接有一个半透明的输入框。点一下日期 → 光标出现 → 打字 → 回车。

写周报

默认：当天日期 + 中等优先级 + Q2 象限。
任务立即出现在日历格子里。

即时创建

从「点新建按钮→填表单→点完成」变成「点日期→打字→回车」，3 步变 1 步

改造 ②：侧面板代替弹窗

点击日历上的任务 → 右侧滑出详情面板（不遮挡日历）。

任务标题 (可编辑)
进度 ▸ 初始
优先级 ▸ 中
项目 ▸ 工作
象限 ▸ Q2
日期 ▸ 5月17日
标签 ▸ + 添加
重复 ▸ 不重复 ▾
子任务 ▸ 0 项

所有字段可编辑，实时保存。日历始终可见。

侧面板详情

替代 EventPopover + TaskDetailModal。信息全在侧面板，不用弹窗、不用切换

改造 ③：日历条上展示更多信息
⬡写周报初始
★修复登录页Bug进行中

图标 = 象限  |  颜色 = 项目或优先级  |  右端文字 = 进度

信息密度提升

不用点进去就知道：什么象限、哪个项目、什么进度

改造 ④：侧边栏 = 过滤器

项目

全部 工作 个人 + 新建

象限

全部 Q1 紧急重要 Q2 重要不紧急

点击过滤器 → 日历只显示匹配任务。
同一数据，不同视角。

侧边栏过滤器

项目、象限变成筛选条件。日历即时响应。不需要「切换视图」

三、最后选择

以上四个改造点的关系是：① 是基础（创建要快）→ ②③ 是核心（信息要看得见）→ ④ 是进阶（组织能力）。

可以一口气全做，也可以分步推进。你怎么看？有没有哪个点你觉得不对、或者想调整的？
