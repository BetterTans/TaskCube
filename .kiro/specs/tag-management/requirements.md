# Requirements — 标签管理面板

## Introduction
当前标签只能通过任务详情中的标签输入框创建和选择。缺少统一的管理界面，无法重命名、删除或为标签设置颜色。

## Boundary
- **In scope**: 标签 CRUD 面板、标签颜色映射、标签合并、批量操作
- **Out of scope**: 标签层级/分组（如 Things 3 的 Areas）

## Requirements

### R1: 标签管理面板
**Objective:** As a 用户, I want 在设置或侧边栏打开标签管理面板

#### Acceptance
1. 面板显示所有已有标签列表（按使用次数排序）
2. 每个标签显示：名称、颜色、关联任务数
3. 从设置页面或侧边栏入口打开

### R2: 标签创建/编辑
**Objective:** 创建新标签、编辑已有标签名称

#### Acceptance
1. 「新建标签」按钮 → 内联输入框 → Enter 创建
2. 点击已有标签名称 → 内联编辑 → Enter 保存
3. 标签名唯一性校验（不区分大小写）
4. 空名称不允许保存

### R3: 标签删除/合并
**Objective:** 删除标签或将标签合并到另一个

#### Acceptance
1. 删除标签时弹出确认（X 个任务将移除该标签）
2. 「合并到...」选项：选择一个目标标签，所有使用该标签的任务自动替换
3. 合并后删除源标签
4. 删除操作不可撤销（警告提示）

### R4: 标签颜色
**Objective:** 为标签设置自定义颜色

#### Acceptance
1. 提供 12 色预设调色板
2. 已有标签自动分配颜色（基于当前 hash 算法）
3. 颜色在任务条和筛选器中显示

### R5: 历史数据兼容
#### Acceptance
1. 标签存储在 task.tags 数组中，格式不变
2. 标签颜色存储在 localStorage（`tagColors` key）
3. 旧数据中的标签自动获得默认颜色
4. 导入导出格式不新增顶级 `tags` 表
